# Crest Website

The official landing page and web portal for [**Crest-Editor**](https://github.com/Crest-Editor-Dev/Crest-Editor) — a high-performance Android code editor built for mobile developers.

🌐 **Live Website:** [crest-editor-dev.github.io](https://crest-editor-dev.github.io/)

---

## ⚡ About Crest-Editor

**Crest-Editor** brings desktop-grade developer workflows to Android devices without compromises:

- **Monaco Editor Engine:** VS Code-like coding experience, touch-optimized for mobile screens.
- **Native UI:** Built with Jetpack Compose & Material 3 for fluid, responsive mobile performance.
- **Linux Sandbox:** Built-in PRoot Linux environment and terminal for real shells, compilers, and dev runtimes.
- **Modern Workflow:** Multi-tab editing, file management, and developer shortcuts right in your pocket.

---

## 🚀 About This Website

A fast, minimalist landing page inspired by Zed's dark developer aesthetic.

- **Stack:** React 18, Vite, Tailwind CSS, Lucide Icons
- **Theme:** Zed-inspired dark canvas, subtle technical grid lines, and electric cyan accents
- **Hosting:** GitHub Pages with automated GitHub Actions CI/CD deployment on push

---

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/Crest-Editor-Dev/Crest-Editor-Dev.github.io.git
cd Crest-Editor-Dev.github.io

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
